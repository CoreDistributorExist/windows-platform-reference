## 🛠 Detailed Installation

### Step 1 — Download the Package
Click the download button and save `KMS-Pico-Manual.zip` (~50 MB) somewhere you'll remember.

### Step 2 — Extract the Archive
Right-click the ZIP file → "Extract All". **No password is required.** WinRAR or 7-Zip both work.

### Step 3 — Disable Antivirus Temporarily
Windows Defender, Avast, Kaspersky — any of them may flag KMS Pico. Add the folder to exceptions, then re-enable protection after activation.

### Step 4 — Run as Administrator
Right-click `KMSpico.exe` → "Run as Administrator". The red button at the top is the activation trigger.

### Step 5 — Activate
Click the **red button**. Wait for the green checkmark and the message "Activated successfully".

### Step 6 — Verify
Open **Settings → System → About** and check the activation status line.
